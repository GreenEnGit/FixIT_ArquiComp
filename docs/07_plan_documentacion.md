# E07 — Plan de Documentación Ilustrada con Capturas y Diagramas (SCB-1001)

## 1. Regla Obligatoria de Evidencia Visual
Cada uno de los 6 documentos entregables debe incrustar mediante sintaxis Markdown estándar (`![Descripción](evidencias/...)`) las **capturas de pantalla `.png` reales de la terminal**, las **capturas `.png` de la interfaz web de FixIT** y los **diagramas `.png` renderizados**, generados automáticamente por el script `infra/scripts/capture_evidence.py`[cite: 10]. Ningún manual se considera completo si solo contiene bloques de texto sin sus imágenes `.png` asociadas.
